이 지도의 데이터

이 화면은 제공한 엑셀의 25척과 항구 30곳을 표시하는 데모입니다. 선박 ID로 기본정보·항차·최신 위치·배정 화물을 연결했습니다.

모든 선박과 위치는 합성 데이터입니다. 실시간 AIS를 수신하거나 실제 배를 추적하지 않습니다.

방향과 연결선

선박 모양은 heading, 진행 방향선은 course를 사용합니다. 북쪽은 0°, 동쪽은 90°입니다. 저속·정박 선박의 0° 값은 실제 선수 방향을 보장하지 않습니다. 점선은 항구를 순서대로 잇는 참고선이며 실제 항로나 항적이 아닙니다.

실시간 연결

AISStream의 PositionReport에서 위도·경도·Sog·Cog·TrueHeading을 받아 지도 데이터로 연결할 수 있습니다. API 키를 보관하는 서버가 필요합니다. 엑셀의 MMSI는 데모 값이므로 실제 선박의 식별번호로 교체해야 합니다.
